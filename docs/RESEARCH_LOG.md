# Research journal

## 2026-11 — Phase 1.2: Understanding EEG

**Focus:** Biological origin of EEG, scalp acquisition, oscillations, sampling,
Nyquist frequency, and 30-second epoch tensors.

**Implemented:**
- Deterministic, synthetic EEG examples for teaching concepts.
- Matplotlib visualizations for action potentials, bands, sampling and stages.
- Epoch segmentation with channels-first tensor shapes.
- Automated tests validating numerical behavior and array shapes.

**Current status:** Coding resources prepared; the lesson is not marked complete
until I have run the notebook, finished the exercises, and answered the quiz.

**Limitations:** These are not real clinical EEG data and no machine-learning
model has been trained or evaluated.

**Next planned topic:** Phase 1.3 — filtering, artifacts, Fourier transform,
power spectral density, and spectrograms.
